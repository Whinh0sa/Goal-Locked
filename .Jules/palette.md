## 2024-05-20 - Replaced Interactive Divs with Semantic Buttons
**Learning:** This app extensively uses `<div>` elements with `onClick` handlers for custom UI controls. While visually styled correctly, they lack keyboard navigability, semantic meaning for screen readers, and focus management. This is a common accessibility issue pattern specific to this apps UI components. Note that `pointerEvents: 'auto'` must still be preserved when switching to a button, since the parent overlays typically use `pointerEvents: 'none'`.
**Action:** When working on UI components in this codebase, prioritize checking for interactive divs and converting them to semantic `<button>` elements with proper aria-labels, preserving necessary `pointerEvents: 'auto'`, and ensuring input elements have associated labels.
